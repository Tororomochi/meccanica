# 百鬼夜行連合学院：花鳥風月部

> Blue Archive crossover reference for Meccanica.
>
> 公式設定をそのまま転載せず、作中で確認できる役割とクロスオーバーでの運用を分けて記載する。

## 概要

花鳥風月部は、百鬼夜行の怪談、物語、噂、幻惑を利用して事件を引き起こす敵対的な集団として扱う。

通常の部活動と同じ感覚で学院運営に参加する組織ではない。怪談を娯楽として語るだけでなく、人の恐怖や思い込みを利用し、物語を現実へ押しつける点が危険性の中心になる。

NPCは実装済み生徒ほどプロフィール情報が揃っていないため、学年、年齢、身長、武器など未確認の数値を推測で補わない。

## コクリコ

### 確認できる人物像

- 花鳥風月部の一員。
- 妖艶で芝居がかった雰囲気を持ち、怪異めいた空間と演出を用いる。
- 京言葉を交えた柔らかな話し方で、相手の逃げ道を塞ぐように誘導する。
- 外見の印象から年齢や立場を断定しない。
- 公式に確認できないプロフィール値は記載しない。

### アンナとの関係

コクリコは、アンナを閉じた舞台へ誘い込み、恐怖や記憶を材料に主導権を取ろうとする。アンナは幻惑を認識しても、その内容を言葉にせず、脱出経路と術者の狙いを探る。

コメディではアンナが怪異の空気を現実的な指摘で崩してもよい。ただし、年齢、身体症状、女性向け医薬品を繰り返し笑いにする旧設定は削除する。

```text
コクリコ：ここでは、隠したものほど鮮やかに見えますえ。
アンナ：見えることと、事実であることは別だ。
コクリコ：まだ、自分で選べていると思うてはるの？
アンナ：選べないと思わせるのが、そっちの仕掛けだろ。
```

## 箭吹シュロ

### 確認できる人物像

- 花鳥風月部の怪談家。
- 自作小説とネット上の情報収集を好み、出来事を物語として組み立てる。
- 噂、観客、仕掛けられた展開を利用し、人々を自分の筋書きへ巻き込む。
- 丁寧な口調を使うが、相手の反応や苦痛を題材として眺める悪意がある。
- 百花繚乱編では、怪談と形代を利用して百鬼夜行の騒乱を拡大させる側に立つ。

### アンナとの関係

シュロはアンナを、秘密が多く物語性の高い題材として扱おうとする。アンナはシュロの構成力を警戒し、事実を隠すだけでなく「解釈できる断片を与えない」ように行動する。

旧資料の「鮎を盗み食いし、ネギ定食で制裁された事件」はクロスオーバー独自設定であり、公式人物像と結びつける根拠が薄いため標準設定から削除する。食事を使う場合も、シュロが場面を演出する小道具として扱う程度に留める。

```text
シュロ：あなたには、よい怪談になりそうな余白がありますね。
アンナ：余白に好きな話を書けば、それは調査じゃなく創作だ。
シュロ：ええ。人が信じれば、創作と現実の境は曖昧になります。
アンナ：だから先に、その観客を切り離す。
```

## 土生アザミ

### 確認できる人物像

- 花鳥風月部の一員。
- 幻惑や精神への揺さぶりを用い、相手が見たいもの、恐れるものを利用する。
- 静かで不穏な圧力をかけ、相手の反応から弱点を探る。
- 他の登場人物から「蛇女」と呼ばれることがある。
- 未確認の学年、年齢、身長、武器は断定しない。

### アンナとの関係

アザミの幻惑はアンナにも知覚されるが、表示された像から核心情報を直接取得することはできない。アンナが無反応なのではなく、反応を観測させないよう制御している形にする。

アンナを精神干渉完全無効の存在にはしない。幻惑は認識負荷や判断遅延を発生させるが、アンナは外部センサー、記録照合、自己診断によって影響を切り分ける。

```text
アザミ：見えているのに、どうして何も感じないふりをするの？
アンナ：感じたものを、お前に報告する義務はない。
アザミ：なら、どこまで隠せるか試してあげる。
アンナ：その間に、現実の位置を特定する。
```

## 三人での運用

- コクリコは舞台と閉鎖空間を作る。
- シュロは噂と物語の筋書きを作る。
- アザミは個人の認識と感情を揺さぶる。
- 三人の能力や情報を完全に同一視しない。
- 花鳥風月部を単なるギャグ要員にせず、物語が人の判断を支配する危険を描く。
- アンナの原初情報、旧素性、本編側軍機は取得させない。
- 幻惑の影響は存在するが、過去の設定を説明する便利な映像装置にはしない。
- 人間相手のアンナはノーキルを守り、拘束、離脱、観客の避難、情報経路の遮断を優先する。
