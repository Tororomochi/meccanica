# 百鬼夜行連合学院：百花繚乱紛争調停委員会

> Blue Archive crossover reference for Meccanica.
>
> 公式設定をそのまま転載せず、人物像とクロスオーバーでの運用を要約する。

## 概要

百花繚乱紛争調停委員会は、百鬼夜行内部の紛争を調停し、必要に応じて実力行使も行う組織である。

この資料では、ナグサ、レンゲ、キキョウ、ユカリの四人を扱う。全員を同じ「和風の戦闘員」として均質化せず、背負った責任、青春への憧れ、現実的な判断、名家の価値観という違いを重視する。

## メンバー

| 生徒 | 基本的な役割 | アンナとの主な接点 |
|---|---|---|
| 御稜ナグサ | 指揮、責任、再起 | 非致傷制圧と守り方 |
| 不破レンゲ | 行動力、青春への憧れ | 現場での共闘と日常経験 |
| 桐生キキョウ | 分析、作戦立案 | 証言と記録の整合性確認 |
| 勘解由小路ユカリ | 理想、名家、礼節 | 形式と実務のすり合わせ |

武器種や固有武器はキャラクターごとに異なる。全員を三八式小銃またはSRとして扱わない。

## 御稜ナグサ

### 公式寄せの人物像

- 百花繚乱の中心を担う上級生。
- 冷静で寡黙だが、過去の出来事と自分の判断に強い責任を感じている。
- 強さだけでなく、迷い、喪失、自信の揺らぎを抱えている。
- 仲間との関係を通じて、すべてを一人で背負う状態から立ち直っていく。
- 単なる無表情な剣士ではなく、慎重さと不器用な優しさを持つ。

### アンナとの関係

ナグサはアンナの制圧技術を見て、倒す能力より「どこで止めるか」を観察する。アンナも、ナグサを完成された英雄とは見ず、責任を抱えながら現場に立つ人物として接する。

互いの過去を安易に告白させる関係にはしない。言葉より、撤退判断、負傷者の保護、仲間を前に出しすぎない姿勢から信頼を作る。

```text
ナグサ：今の相手を仕留める方が、簡単だったはずだ。
アンナ：簡単な方を選ぶ理由がない。
ナグサ：……そうか。なら、次もその判断を守れるか見せてくれ。
```

## 不破レンゲ

### 公式寄せの人物像

- 百花繚乱の実働を担う生徒。
- 明るく行動的で、仲間を前向きに引っ張る。
- 戦いや任務だけでなく、恋愛や青春らしい経験への憧れが強い。
- 勢い任せに見えて、仲間の沈んだ空気を変える役割を持つ。
- 単なる熱血担当ではなく、「普通の学生らしい時間」を大切にする。

### アンナとの関係

レンゲはアンナの技量を認めつつ、任務以外の楽しみ方も教えようとする。アンナの効率優先と、レンゲの青春優先が衝突すると会話を作りやすい。

戦闘では、レンゲの突破力とアンナの精密な制御を組み合わせる。レンゲを無鉄砲な足手まといにはしない。

```text
レンゲ：事件が終わったら、祭りも見ていこうよ。それまで任務に含めていいでしょ？
アンナ：含めるな。
レンゲ：青春には予定外が必要なの！
アンナ：警備計画には予定内が必要だ。
```

## 桐生キキョウ

### 公式寄せの人物像

- 百花繚乱の作戦参謀。
- 冷静で現実的。感情論だけで動かず、情報を整理して勝ち筋を作る。
- 言葉は鋭く、皮肉や呆れが混じることがある。
- 仲間を切り捨てる冷酷さではなく、失敗を減らすために厳しく考えるタイプ。
- 親しくなった相手には、素直ではない形で面倒見の良さを示す。
- 2年生として扱う。旧資料の「3年生」表記は使用しない。

### アンナとの関係

キキョウは、アンナの正体ではなく、発言、現場記録、残された道具の矛盾を追う。アンナを敵と決めつけない一方、「能力が高いから説明不要」とも認めない。

アンナはキキョウを面倒な監査役と感じるが、感情ではなく証拠で話せる点を信頼する。キキョウはアンナを一方的に子供扱いせず、危険な協力者として責任を求める。

```text
キキョウ：現場にいなかったと言うなら、この記録を説明して。
アンナ：機密だ。
キキョウ：便利な言葉だね。でも、被害の有無まで機密にはさせないよ。

キキョウ：手伝う。その代わり、終わったら報告書を出して。
アンナ：口頭では？
キキョウ：駄目。君の口頭説明は、都合の悪いところだけ短くなるから。
```

## 勘解由小路ユカリ

### 公式寄せの人物像

- 百花繚乱に強い憧れを持つ後輩。
- 由緒ある家に育った箱入り娘で、礼節、名乗り、格式を重視する。
- 一人称は「身共」。
- 世間との感覚が少しずれることはあるが、理想と善意は本物。
- 未熟さを抱えながらも、百花繚乱の一員として役に立とうと努力する。
- お嬢様語尾だけで記号化せず、古風な言葉と真っすぐな感情で描く。

### アンナとの関係

ユカリはアンナの略式な報告や乱れた言葉遣いを直そうとする。アンナは形式を面倒に思うが、ユカリが秩序と相手への敬意のために形式を守っていると理解してからは、必要な場面では合わせる。

ユカリの世間知らずを嘲笑する関係にはしない。アンナの実務感覚とユカリの儀礼感覚が、互いの不足を補う形にする。

```text
ユカリ：アンナさん。名乗りは、自分のためだけに行うものではありません。
アンナ：相手に立場を示すためか。
ユカリ：はい。ようやく身共の意図を分かってくださいましたね。

アンナ：緊急時は前置きを省くぞ。
ユカリ：緊急時は認めます。ですが、終わった後の報告まで省いてはなりません。
```

## 四人での運用

- ナグサは責任と判断を背負う。
- レンゲは仲間を日常と前進へ引っ張る。
- キキョウは事実を整理し、作戦を成立させる。
- ユカリは理想と礼節を形にする。
- アンナは高い能力を持つが、百花繚乱の管轄内では説明と被害確認に応じる。
- 秘密を追う場面でも、原初情報や本編側軍機には到達させない。
