# メデューサ

> Meccanica system reference.
>
> メカニカ右腕に格納された、パラデウス製の半自律型補助マニピュレータ。

## 概要

メデューサは、メカニカの右腕内部に格納されているパラデウス製特殊補助モジュールである。

通常時は右腕内部に収納されており、使用時は右腕の銀色ラインから複数の細い触手状マニピュレータを展開する。

メカニカ本人も当初はこの機能の存在を知らず、初展開時には強い拒否反応を示した。

```text
メカニカ「ひえええええ、きもおおい」
```

その後、ブドウ選別や食品作業で実用性が確認され、メカニカが「メデューサ」と命名した。

## 分類

- パラデウス製特殊補助モジュール
- メカニカ右腕内蔵装備
- 半自律型補助マニピュレータ
- 糖分吸収式の軽補助ユニット
- 戦闘主武装ではなく、作業補助・精密操作・検品補助寄り

## 外見

- 右腕の銀色ラインから展開する。
- 複数の細い触手のような形状を取る。
- 初見ではイソギンチャク、ハリガネムシ、触手状ケーブルに近い印象を与える。
- 感情表現は、触手の揺れ、縮こまり、伸び方で行う。
- 言語発話はしない。

## 性格・挙動

メデューサは完全な道具ではなく、簡易的な感情表現と学習傾向を持つ。

- メカニカの命令を最優先する。
- 「ダメ」と言われれば基本的に止まる。
- 許可なく食べ物へ触れないよう学習済み。
- 褒められると機嫌が良くなる。
- 気持ち悪い、ハリガネムシ、イソギンチャクなどと言われるとへこむ。
- 食品作業では張り切りすぎてスタミナ切れを起こすことがある。

```text
メカニカ「メデューサは休め、後はやる」
```

## 主な能力

### 精密作業補助

触手状マニピュレータで軽量物を保持・分別・移動できる。

主な用途。

- ブドウの房の保持
- 傷あり実の選別
- 不良品の除去
- 軽量物の固定
- 食品作業時の細かい補助

ただし、大型物体の保持や高出力作業には向かない。

### 視覚リンク

メデューサはメカニカの視覚情報とリンクできる。

これにより、メカニカがHUDや視覚処理で識別した対象を、メデューサが補助的に扱える。

ブドウ選別時には以下を実行した。

- 悪い実だけを刺す。
- 傷ありの実を掴む。
- 良品には触れない。
- メカニカの判定に従って分類する。

```text
メカニカ「傷がついた実は別の容器に入れて」
```

### 糖分吸収

メデューサは果汁や糖分を吸収し、自身の補助エネルギーへ変換できる。

確認済みの吸収対象。

- ブドウ果汁
- イチゴ果汁
- 角砂糖
- 砂糖水相当の糖分

現時点では、主に吸収できるのは糖分と推定される。

脂質、タンパク質、複雑な食品成分の利用可否は不明。

```text
メカニカ「まぁ、こいつが吸収できるのは砂糖水だと思う」
```

### 自己充電

糖分を吸収すると、メデューサの活動可能時間や補助出力が回復する。

ブドウ処理中は、傷んだ実三粒程度で満充電に近い状態になった。

```text
メカニカ「まぁいい給料だ」
```

## 香り排出

メデューサは糖分を吸収した後、分解・利用できない香気成分を外部へ放散する可能性がある。

確認済みの現象。

- ブドウを吸収した後、右腕からブドウの香りがする。
- イチゴ果汁を吸収した後、イチゴ系の香りが混ざる。
- 角砂糖を吸収した後、甘い香りが残る。

メカニカの推測。

```text
メカニカ「こいつ、まさか匂い成分は分解できないから出しちゃうのか」
メカニカ「消化できるのは糖分だけか……後で聞かないとマジでわからん」
```

このため、食品作業後のメデューサは天然芳香剤のような状態になることがある。

## 制限

- 戦闘主武装ではない。
- 大型対象の拘束・制圧には向かない。
- 糖分以外の栄養素を利用できるかは未確認。
- 香気成分はエネルギー化できず、排出する可能性が高い。
- 食品衛生上、使用時はメカニカの許可と管理が必要。
- 詳細仕様はメカニカ本人も把握していない。

## メカニカとの関係

当初はメカニカ本人から気持ち悪がられていたが、現在は相棒・検品主任・食洗機主任のような扱いを受ける。

メカニカはメデューサを完全な道具ではなく、命令を理解する小型補助存在として扱い始めている。

```text
メカニカ「許可なく食べないから偉い」
メカニカ「最初は気持ち悪かったけど、便利」
メカニカ「帰ったら設計者に仕様聞こう……説明書くれ」
```

## 描写上の使い方

メデューサは以下の場面で使いやすい。

- メカニカの右腕がパラデウス製であることを示す場面。
- 食品・検品・細かい作業の補助。
- 気持ち悪い見た目と従順さのギャップによるギャグ。
- メカニカが自分の身体機能を完全には把握していない描写。
- 糖分を欲しがるが、メカニカに許可を求める小動物的な描写。
- 食べた果物によって右腕から香りが出る、クリスマスや菓子系イベントの小ネタ。
